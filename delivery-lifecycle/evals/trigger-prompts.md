# Trigger Prompts

Should trigger (yes) and should not (no; the better skill is noted).

## delivery-lifecycle
| | Prompt |
|---|---|
| yes | I have an idea for a booking app; take it all the way: build it, test it, write the docs, and get it ready to ship |
| yes | Take this from idea to release, with tests, docs and a changelog |
| yes | Full delivery workflow for the export feature |
| no | Just build the booking app (dev-lifecycle) |
| no | Run QA on the checkout feature (qa-lifecycle) |
| no | Write the docs for what we built (docs-lifecycle) |
